## 每一轮进步

### 1. 读懂算法

[01-algorithm.md](01-algorithm.md)

原以为会是模型直接预测开孔。读完代码后：玩偶只在背面放约 32 mm 候选框，用 9×9 射线测深度和壁厚，合格后再布尔挖洞、做随形盖板。视觉当时是可选的，默认关闭。

### 2. 提出加速方案

[02-speed-plan.md](02-speed-plan.md)

基线 73s。真正贵的不是盖板，是「每个候选都打满射线」和「朝向在 39 万面上打分」。方案定为：粗搜再精搜、搜索代理、跳过无意义的 1.1 倍放大循环。终验（壁厚 / 穿透 / 干涉）不砍。

### 3. 73s → 57s

[03-speed-57s.md](03-speed-57s.md)

把方案落到生产路径：朝向法线聚类向量化、选面先粗后精、深度余量够就跳过 21×21 密铺。`--back-only` 时不再重复探背面。输出仍通过终验，开孔还在背面中线。

### 4. 57s → 16s

[04-print-50k.md](04-print-50k.md)

用户认为打印精度不需要 392k 面。300 mm 摆件、0.4 mm 喷嘴，3–8 万面足够。加载后先减到默认 5 万面，Manifold、布尔、STL 回读一起变便宜。这是整段调试里最大的一跳。

### 5. 16s → 11.5s

[05-speed-11s.md](05-speed-11s.md)

5 万面已经闭合，不必再修一遍拓扑，也不必做空壳射线诊断。选面从 110 个点收到 16 个。剩下约 4s 是 GLB 读取 + 减面 + Manifold，再压主要靠 `--print-faces 20000`。

### 6. 接入视觉

[06-vision-setup.md](06-vision-setup.md)

几何能找「能挖的洞」，不能认脸。接上 `deepseek-v4-flash-vision-exp`，让它看六张环视，指出正面 / 背面和开孔画面坐标。深度和壁厚仍由几何终验说了算。

### 7. 第一次视觉跑偏

[07-vision-wrong.md](07-vision-wrong.md)

减面后水平 PCA 把模型拧了 82°（原网格是 180°）。视觉在侧视上判正反，又把提示词里的示例 `u=0.5, v=0.55` 原样抄回。几何搜索再丢掉视觉点，实际开孔落到 `(8.0, 44.7)`，太靠下。

### 8. 开孔回到上背

[08-vision-fix.md](08-vision-fix.md)

三处一起改：接近 90° 的 PCA 直接拒绝；提示词禁止抄数字、要求上背肩胛；视觉 UV 随 yaw 转到模型坐标，不再被躯干中心覆盖。重跑后开孔在 `(-7.2, 103.3)`，比上一刀明显更高。
